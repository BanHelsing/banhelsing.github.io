Computer Vision Developer, Scrum Master, and sole developer of the video-analysis CLI
Software Fair Project, Universidad Técnica Federico Santa María, 2025

The system analyzed blasting footage to detect and track flyrocks. The CLI used frame differencing, morphological filtering, contour analysis, and temporal trajectory association with OpenCV.

  • Converted trajectories from pixels to estimated metric coordinates using camera parameters.
  • Calculated distance, maximum velocity, direction, trajectories, risk levels, and a safety perimeter.
  • Generated annotated video and structured JSON outputs.
  • Supported batch processing integrated with the project API.
